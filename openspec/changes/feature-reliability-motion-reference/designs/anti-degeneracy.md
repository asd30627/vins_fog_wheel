# 設計短文 — 防可靠度退化至零(T4)

**推薦預設:每幀保留 reliability 最高的至少 N=30 個特徵(硬下限),且權重正規化避免集體歸零;以全動態視野情境驗證。**

## 風險
所有特徵被降權至 0(視野被動態物體佔滿、或 d² 系統性偏高如外參/同步退化)→ 視覺殘差全失 → 最佳化退化、僅剩 IMU/wheel dead-reckoning → 漂移。

## 機制(兩層)
1. **每幀最小可信特徵下限**:依 reliability 排序,強制保留前 N 個(N=30,沿 integrity reliability_state.min_features_per_frame),即使其可靠度低於門檻——寧可信任「相對最可信」者也不留空。
2. **權重正規化/地板**:逐特徵 alpha 設地板 α_floor>0(如 0.05),保證每個進圖特徵有非零權重;避免數值上等同剔除全部。

## 驗證法
- **構造情境**:CARLA dynamic_dense 取視野被車佔滿的片段(或合成全動態遮蔽窗),確認系統不崩、有效特徵數 ≥ N。
- **退化偵測指標**:每幀有效特徵數、可靠度分布的 5th percentile;若 5th pct→0 且有效數<N → 觸發下限保護(log 記錄)。
- **與 baseline 對照**:退化情境下 B1(含本機制)不應比 B0 更差(防退化閘,沿 v3.1:clean ATE p95 不惡化>20%)。

## 非目標
不處理「外參/同步本身錯誤」造成的全域高 d²(那是標定問題,由 motion-reference-consistency 的 sanity 把關,非本機制職責)。
